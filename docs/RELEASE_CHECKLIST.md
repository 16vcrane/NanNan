# Phase 10 发布门禁

## 自动化回归

开发环境完整检查：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\release-check.ps1 -SkipExternalChecks
```

配置 `.env.production` 和正式 API 域名后执行最终门禁：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\release-check.ps1
```

两条命令都必须成功，且工作区不得包含真实密钥。

## HTTPS 与域名

- [ ] 域名已备案并解析到生产服务器
- [ ] Caddy 成功签发证书，证书链受 iOS/Android 信任
- [ ] HTTP 自动跳转 HTTPS
- [ ] 健康检查响应包含 HSTS、安全头和请求 ID

## 隐私合规

- [ ] 微信隐私保护指引已声明登录、选择图片和本地缓存用途
- [ ] AI 使用说明、隐私政策、用户协议可从“设置”访问
- [ ] 文案中的模型数据范围与当前实现一致
- [ ] 数据管理页可删除账户和全部数据
- [ ] 删除后旧 token 无法继续访问，私有图片对象已清理

## 真机测试

至少覆盖一台当前 iOS 微信和一台当前 Android 微信：

- [ ] 首次启动与微信登录
- [ ] 情绪选择、中文多行输入和草稿恢复
- [ ] 相册与相机图片各上传一次，最多三张
- [ ] 长按拖动图片排序、删除图片
- [ ] 保存日记、AI pending/success/failed 状态
- [ ] 时光分页、筛选、图片加载和详情返回刷新
- [ ] 退出登录、重新登录、单篇删除和账户删除
- [ ] 全面屏底部安全区、系统字体放大和深色模式可读性

记录测试设备、系统版本、微信版本、时间和结果。真机测试不能由模拟器结果替代。

## 弱网测试

分别在微信开发者工具的 Slow 3G、离线模式和真机网络切换下验证：

- [ ] 保存超时后正文、情绪和图片草稿仍存在
- [ ] 网络恢复后重试复用幂等键，不产生重复日记
- [ ] 图片上传失败可重试，失败图片不阻止文字保存
- [ ] AI 失败不影响日记保存，稍后可重试
- [ ] 时间轴加载失败保留已有内容并提供重试入口
- [ ] `429` 和 `503` 显示可理解的提示，不清空用户输入

自动化测试覆盖草稿保留和幂等键复用，但真实网络切换仍需真机确认。
